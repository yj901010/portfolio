# TlatFarm 공개 내용의 근거

확인일: 2026-09-17. 재직 당시 기여를 설명하는 포트폴리오이며, 현재 운영 시스템 전체를 재현한 아키텍처 문서가 아니다.

## 구성

기존 프로젝트 상세 레이아웃에 담당 업무, 네 가지 기여 요약, 세 가지 구현 사례를 배치한다. Cloud Run 비동기 실행 사례를 먼저 보여주고 Pub/Sub 수신, BigQuery 집계 연동으로 이어진다. 빌드·실행 환경은 Cloud Run 사례의 별도 보기로 연결한다. 총 여섯 개 도식 보기를 제공한다.

## 근거와 담당 범위

| 항목 | 근거 | 공개 설명 |
| --- | --- | --- |
| 서비스 목적 | 사용자 설명, 제공된 서비스의 읽기 전용 화면 확인 | 드론이 구역별 촬영한 이미지를 AI로 분석해 작물 상태와 병해충을 확인하는 스마트팜 |
| Pub/Sub 수신 | 사용자가 설명한 재직 당시 담당 업무 | Pub/Sub으로 전달되는 드론 데이터를 Spring Boot에서 수신·처리 |
| 비동기 실행 문제 | 사용자 설명, 개인 기술 글, Google 공식 CPU 할당 문서 | 요청 종료 뒤의 CPU 할당 제한을 확인하고 작업을 Cloud Tasks의 별도 HTTP 요청으로 실행 |
| 드론 예약 | 사용자 설명 | 재직 당시 Cloud Tasks를 드론 예약 운행에 활용 |
| 에너지 데이터 | 사용자 설명 | BigQuery에 적재된 태양광·풍력 데이터 집계 및 Spring 연동 |
| 빌드·런타임 | 사용자 설명과 블로그의 배포 흐름 그림 | Cloud Build 기반 이미지 빌드와 Cloud Run 실행 환경을 다룬 경험 |
| 참여 기간·수상 | 기존 PDF와 사용자 정정, CES 공식 소개 | 2025.08~2026.02.01 참여. CES 수상은 경력 화면에서 참여 프로젝트의 성과로 표시 |

작물 분석·촬영 이력·에너지 추이 화면은 제품의 기능을 이해하는 데만 활용했다. 운영 화면의 존재가 본인의 구현이나 과거 소스 구조를 증명하지는 않는다. 소스 저장소를 확보하지 못했으므로 코드 검증이나 작성자 분석을 완료했다고 표현하지 않는다.

## 표현 경계

- AI 분석은 서비스 전체의 기능이다. 개인 기여 도식은 데이터 수신·처리와 작업 실행에 한정하고 AI 모델 개발·정확도 개선은 주장하지 않는다.
- 드론 메시지의 스키마, 이미지 원본의 전송 경로, Pub/Sub push/pull 방식, GCS 업로드·AI 웹훅·저장 엔티티 매핑은 확인되지 않았다. 기존 상세 데이터의 해당 설명은 제거했다.
- 블로그의 구체적인 재현 예시는 Contact 폼의 메일 발송이다. 이를 드론 예약 코드의 증거로 바꾸지 않는다. 현재 운영 사이트의 예약 기능 유지 여부도 단정하지 않는다.
- CPU throttling과 scale-to-zero는 구분한다. 최저가 요금제, CPU가 정확히 0%, 재시도·멱등성 보장, 비용·성능 개선 수치는 추가하지 않는다.
- BigQuery의 원천 적재 파이프라인을 본인이 만들었다고 하지 않는다. 집계 SQL, 기준·주기, Scheduled Queries 여부는 특정하지 않는다.
- 배포 자동화 전체 구축, 무중단 배포·자동 롤백, 레지스트리·권한 설정의 단독 구현을 주장하지 않는다. 빌드·실행 도식은 경험한 환경의 개요다.
- 확인되지 않은 팀 인원·역할별 인원 표시는 제거했다. 표지는 드론·농장을 주제로 생성한 이미지로 교체했다. 실제 현장이나 운영 화면을 나타내는 증빙이 아니며, 실데이터·접속 정보는 포함하지 않는다. 생성 정보는 [TLATFARM_ARTWORK.md](TLATFARM_ARTWORK.md)에 기록한다.
- 채용 화면에는 커밋 목록·코드 위치·남은 과제 목록을 넣지 않는다. 구체적인 기여와 선택 이유를 설명하고, 출처는 개인 기술 글로 연결한다.
