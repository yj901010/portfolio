# K-HOPE 공개 콘텐츠 편집 기준

API 기여는 사용자가 지정한 업무 저장소의 커밋과 작성 이력을 로컬에서 대조했다. 당시 작업 중인 파일과 미추적 자료는 근거에 포함하지 않았다. 이후 사용자가 본인의 작업으로 별도 제공한 두 Airflow DAG는 제공 파일의 구현을 정적으로 검토해 추가했다. 업무 저장소와 DAG 원본은 변경하지 않았다.

## 공개한 담당 범위

- 연구 조건 관리 API와 AI 응답을 서비스 요청·응답 구조에 연결한 작업
- 조회 응답·파일 다운로드의 공통 출력 정의
- 실행 중인 작업 등록, 취소 요청과 실행 중단·리소스 정리 연계
- 외부 스트림 수신과 WebSocket 전송 작업의 분리
- 비동기 결과의 요청·상태 확인, 결과 저장과 화면 알림
- Airflow 데이터 복사: 서버 측 커서·청크 조회, 일괄 INSERT·청크별 커밋, 누적 적재 건수 확인
- Airflow 일별 집계: 기존 결과 확인·재집계 분기, 동적 태스크 매핑·동시 실행 제한, 단일 집계 값 확인과 결과 요약

Airflow 내용은 제공 코드에서 확인한 구현 범위다. 실제 연결·운영 실행을 검증한 것은 아니다. 데이터 복사는 전체 교체 방식이며 전체 작업을 하나의 원자적 트랜잭션으로 표현하지 않는다. 집계도 재실행의 완전한 멱등성이나 모든 실패 경로의 감지를 보장한다고 쓰지 않는다. 내부 스케줄 시각·처리 크기·대상 선정 규칙·접속 설정은 공개하지 않는다.

도식은 위 기여를 설명하기 위한 일반화된 처리 흐름이다. 실제 시스템 전체의 구성도나 운영 화면을 복제하지 않는다. AI 모델 개발, 플랫폼 전체 설계, 성능 수치, 분산 환경의 정확히 한 번 처리, 운영 안정성 보장으로 확대하지 않는다.

## 공개 저장소에도 포함하지 않는 자료

업무 저장소 주소·경로·커밋 식별자, 내부 API·호스트·네트워크 구성, 인증 정보, 실제 데이터·샘플·화면, DB 테이블·필드, 쿼리 원문, 상세 임상·업무 판정 규칙, 미공개 운영 설정 및 소스 코드 발췌는 공개 콘텐츠와 문서·PR에 포함하지 않는다.

공개 화면의 외부 링크는 기존 K-HOPE 공식 사업 소개만 사용한다. 공개 분량을 늘리기 위해 확인되지 않은 기여를 추가하지 않는다. 제공받은 업무 코드나 DAG를 공개 저장소에 복사하지 않는다.
